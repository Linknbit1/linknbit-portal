  *not client visible*, and so is every project except Cricket Sansar — that is the default, not a
  decision anyone made. This list is therefore a judgement call, not a filtered export. Please read
  each section before it goes out.
- **Oasis has no client record linked in the portal**, although it is clearly client work. It has
  been included above. Worth linking the client properly in the portal.

**On the descriptions:** the internal task notes are written as instructions to our team ("Please
create…", "The client wants…", "Get it done ASAP"). They have been rewritten as statements of what
was delivered. Implementation detail that should not leave the office — an embed script and API
key, an internal Figma link, and staff names — has been summarised rather than quoted.

**Six items had no description recorded in the portal**, so their line above is drawn from the task
title alone: Zedan's product detail section, Zedan's deployment/fixes, Zedan's awareness ads plan,
the two Azaadi posts, and Neowall's ad creatives. Add a sentence to any of these if the client needs
